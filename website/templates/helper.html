Mosque timetable helper

Sajda cannot search mosques for you (that would break the timetable provider terms). This page helps you do it yourself in 2 minutes - everything runs in your browser. No API calls, no scraping, no data leaves your Mac. You visit the provider site, you download your file, you import it into Sajda.

  1. Find your mosque page (tool 1).
  2. Read the mosque ID off that page - bottom-left corner or one click on the bookmark button (tool 2).
  3. Open the calendar download link it builds (tool 3), download the annual PDF (easiest - one file) or the ZIP/CSVs.
  4. In Sajda: Settings > Mosque Timetable > Import timetable, pick the file, then rename it with the pencil button.

1 - Find your mosque

Type your mosque or city, then open the search. It goes to DuckDuckGo public results (limited to the provider site) in a new tab - pick your mosque there and copy its address.

Opens DuckDuckGo results in a new tab.

2 - Find the mosque ID on the page

Mosque addresses are usually name-based (e.g. .../grande-mosquee-de-paris) with no ID inside - the ID is printed on the page itself, bottom-left corner:

No bookmark bar? Drag this button up there, then click it while viewing any mosque page - it reads the ID from the page itself: Get mosque ID

3 - Open the calendar download page

The calendar lives at .../calendar/ID/choice. Enter the ID and open it - then download the file yourself.

Nederlands - Francais - English

Custom .../m/... addresses have no numeric ID - on those pages just use the site own download button instead of this trick.

Why this way?

Looking timetables up from inside the app would use the provider service against their terms, so Sajda reads only files you hand it (Settings > Mosque Timetable, stored locally, fully offline). This helper is the middle ground: it never contacts the provider - you do, in your own browser, exactly as if you bookmarked the page.
